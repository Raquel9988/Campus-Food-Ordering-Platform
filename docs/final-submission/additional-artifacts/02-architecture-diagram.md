\# Architecture Diagram



This folder contains the architecture diagram for the Campus Food Ordering Platform.



The architecture diagram shows the main system components and how they interact, including:



\- Student frontend

\- Vendor frontend

\- Admin frontend

\- Supabase authentication

\- Supabase database

\- Cloudflare Pages / Functions

\- PayFast Sandbox payment flow

\- Analytics API

\- GitHub / CI-CD workflow
