\# UML Activity Diagram Summary



The included UML activity diagram shows the main workflow of the Campus Food Ordering Platform.



It includes the following swimlanes:



\- Student

\- System

\- Payment Gateway

\- Vendor

\- Admin



The diagram shows how the system handles:



\- User registration and login

\- Role-based behaviour

\- Vendor approval and suspension

\- Dietary tag management

\- Student menu browsing

\- Cart management

\- One-vendor cart restriction

\- PayFast payment request and payment processing

\- Paid order creation

\- Vendor order processing

\- Order status updates

\- Student active orders and order history

\- Sprint 4 analytics data preparation

\- Admin analytics dashboard

\- Sales per vendor report

\- Peak ordering hours report

\- Custom analytics view

\- CSV/PDF report export
