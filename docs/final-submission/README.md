\# Project Summary



The \*\*Campus Food Ordering Platform\*\* is a web-based food ordering system for campus users.



The system supports three main user roles:



| User Role | Purpose |

|---|---|

| Student | Browse menus, place orders, pay, track active orders, and view order history |

| Vendor | Manage menu items, view paid orders, and update order status |

| Admin | Manage vendors and view analytics reports |



The project was developed across four sprints using Scrum methodology.
