## How to access the evidence

1. Open the project folder on github.
2. Go to `docs/final-submission/scrum-methodology/evidence`.
3. Open `Sprint_Backlogs_Evidence.pdf`.

## What the Word document contains

The Word document contains the Sprint Backlogs evidence for Sprints 1 to 4. It includes each sprint goal, the selected backlog items/user stories, assigned feature areas, estimated story points, dependencies, final status, GitHub Project board links, dependency notes, and sprint outcomes.

This document supports the Scrum methodology requirement for Sprint Backlogs.
