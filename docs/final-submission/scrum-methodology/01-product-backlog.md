\# Product Backlog



This document contains the prioritised product backlog for the Campus Food Ordering Platform.



The backlog includes the main features, enhancements, and fixes planned throughout the project.  

Items were managed using GitHub Issues and GitHub Projects across Sprint 1, Sprint 2, Sprint 3, and Sprint 4.



\## Product Backlog Table



| Priority | Backlog Item | User Story / Purpose | Main Sprint | Status |

|---|---|---|---|---|

| High | Student authentication | As a student, I want to sign up and log in so that I can access the food ordering platform. | Sprint 1 | Done |

| High | Vendor authentication | As a vendor, I want to register and log in so that I can manage my food business on the platform. | Sprint 1 | Done |

| High | Admin authentication and role-based access | As an admin, I want protected admin access so that only authorised users can manage the system. | Sprint 1 | Done |

| High | Vendor approval and suspension | As an admin, I want to approve or suspend vendor accounts so that only valid vendors can use the platform. | Sprint 1 | Done |

| High | Menu item creation and editing | As a vendor, I want to add and edit menu items so that students can view my available food. | Sprint 1 | Done |

| High | Menu display and availability | As a student, I want to view menu items and availability so that I know what food can be ordered. | Sprint 1 | Done |

| High | Cart functionality | As a student, I want to add menu items to a cart so that I can prepare my order before checkout. | Sprint 2 | Done |

| High | Place order functionality | As a student, I want to place an order so that vendors can prepare my food. | Sprint 2 | Done |

| High | Orders database and backend logic | As the system, I want to store orders and order items so that order information is saved and retrievable. | Sprint 2 | Done |

| High | Vendor orders dashboard | As a vendor, I want to view incoming orders so that I can prepare customer orders. | Sprint 2 | Done |

| High | Order status management | As a vendor, I want to update order status so that students can track order progress. | Sprint 2 | Done |

| Medium | Student order tracking | As a student, I want to view my orders so that I can track my purchases and order status. | Sprint 2 | Done |

| Medium | Real-time updates and notifications | As a student or vendor, I want order updates to appear live so that I do not need to refresh manually. | Sprint 2 | Done |

| High | Online payment API | As the system, I want to connect to PayFast so that student payments can be processed securely. | Sprint 3 | Done |

| High | Order and payment linking | As the system, I want to link payments to orders so that only paid orders are processed. | Sprint 3 | Done |

| High | Payment UI | As a student, I want a payment interface so that I can complete checkout. | Sprint 3 | Done |

| High | One-vendor cart rule | As a student, I want to order from one vendor at a time so that payment and order tracking stays simple. | Sprint 3 | Done |

| Medium | Active orders and order history | As a student, I want active and completed orders separated so that I can track current and past orders clearly. | Sprint 3 | Done |

| Medium | Dietary tag selection for vendors | As a vendor, I want to assign dietary tags to menu items so that items are properly classified. | Sprint 3 | Done |

| Medium | Dietary backend storage | As the system, I want to store dietary data so that it can be used for filtering. | Sprint 3 | Done |

| Medium | Dietary filtering for students | As a student, I want to filter menu items by dietary needs so that I can find suitable food. | Sprint 3 | Done |

| Medium | Analytics backend/data preparation | As an admin, I want clean analytics data so that reports show correct sales and order information. | Sprint 4 | Done |

| Medium | Analytics dashboard layout | As an admin, I want one clear analytics dashboard so that I can view all reports in one place. | Sprint 4 | Done |

| Medium | Sales per vendor report | As an admin, I want to view sales per vendor over time so that I can understand vendor performance. | Sprint 4 | Done |

| Medium | Peak ordering hours report | As an admin, I want to see peak ordering hours so that I can understand when students order most. | Sprint 4 | Done |

| Medium | Custom analytics view | As an admin, I want filtered analytics views so that I can analyse specific data. | Sprint 4 | Done |

| Medium | Export reports | As an admin, I want to export reports as CSV or PDF so that I can save or share analytics results. | Sprint 4 | Done |
