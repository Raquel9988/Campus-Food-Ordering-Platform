# Product Backlog Evidence

This folder contains the Product Backlog evidence for the Campus Food Ordering Platform.

## Evidence Document

The full product backlog evidence is stored in the Word document below:

`Product_Backlog_Evidence.docx`

## File Location

Save or keep the Word document in this folder:

https://github.com/Raquel9988/Campus-Food-Ordering-Platform/tree/main/docs/final-submission/scrum-methodology/evidence

## How to Access the Evidence

1. Open the project folder on your github.
2. Go to `docs/final-submission/scrum-methodology/evidence`.
3. Open `Product_Backlog_Evidence.pdf`.
4. The Word document contains the prioritised product backlog, GitHub Projects evidence links, sprint board links, backlog summary table, and supporting evidence list.

## Purpose

This evidence supports the Scrum methodology requirement for maintaining a Product Backlog. The Word document shows the features, user stories, priorities, sprint allocation, and final status of the backlog items used during the project.
